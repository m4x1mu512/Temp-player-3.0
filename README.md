# Темп — Локальный музыкальный плеер для Android

Красивый локальный музыкальный плеер без серверов, регистрации и внешних API.

## Возможности

- 🎵 Воспроизведение локальных аудиофайлов (MP3, M4A, AAC, FLAC, OGG, Opus, WAV, 3GP)
- 🎨 Современный интерфейс на Jetpack Compose + Material 3
- 🌙 Поддержка светлой и тёмной темы
- 🎛️ 5-полосный эквалайзер с пресетами
- 📊 Визуализация музыки (Спектр, Волна, Круг)
- ⏰ Таймер сна
- 📱 Фоновое воспроизведение с уведомлением
- 💾 Локальная база данных Room
- ⭐ Избранное и плейлисты
- 🔍 Поиск по медиатеке

## Требования

- Android 8.0 (API 26) и выше
- Разрешение на доступ к аудиофайлам
